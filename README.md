# homebrew-guma

Homebrew tap for [guma](https://github.com/GarroshIcecream/guma) — a parallel
disk analyser for macOS.

```sh
brew tap GarroshIcecream/guma
brew install guma
```

`Formula/guma.rb` is written by cargo-dist on every release of the source
repository. Do not edit it here; change it in
[GarroshIcecream/guma](https://github.com/GarroshIcecream/guma) and cut a tag.
